# OpenGOAL Level Tools — User Guide

Make custom Jak and Daxter levels in Blender with the OpenGOAL Level Tools add-on.
New here? Read **Part 1** in order. The other parts can be read in any order.

1. [Install](install.md) — Blender, OpenGOAL, the add-on and its preferences
2. [Your first level](first-level.md) — from an empty file to walking around in game

4. [Build & Play](build-and-play.md) — exporting, compiling, launching, boot modes
